## 一、核心算法机制

### CES 评分体系（流量分配核心）

| 互动行为 | 权重 |
|----------|------|
| 点赞 | ×1 |
| 收藏 | ×1 |
| 评论 | ×4 |
| 转发 | ×4 |
| 关注 | ×8 |

> **评论权重是点赞的 4 倍，关注是 8 倍。** 必须引导评论和关注才能进入更大流量池。

### 流量池阶梯

1. **冷启动（黄金 2 小时）**：200-500 曝光，根据点击率和互动率决定下一步
2. **门槛指标**：图文点击率 ≥ 2.5%，互动率 ≥ 5%
3. **2026 新增 CQS（内容质量分）**：低于 60 分即使 CES 高也会隐形限流

## 三、晚霞账号内容策略

### 内容矩阵

| 类型 | 频率 | 目的 |
|------|------|------|
| **每日预报** | 每天 | 核心 IP，提供当日晚霞概率/等级/观赏时间 |
| **知识科普** | 每周 1-2 篇 | 教粉丝看云识霞，建立专业信任 |
| **粉丝返图** | 每周 1 篇 | UGC 二次传播，增强社区感 |
| **机位攻略** | 每周 1 篇 | 城市最佳观赏点 + 拍摄参数 |
| **重大天气解读** | 按事件 | 台风/寒潮/高温等热点蹭流量 |

### 内容温度公式

> 不只是冷冰冰的数据 → 而是帮人「知道什么时候抬头，能看见最美丽的云霞」

```
专业预报 + 人文温度 + 城市归属感 = 粉丝粘性
```

### 夏天是黄金期

- 雨后初晴、大风过后空气干净 = 火烧云最佳时机
- 暑假学生党活跃，话题参与度高

## 四、笔记生产规范

### 封面设计

| 原则 | 具体要求 |
|------|---------|
| 尺寸 | **3:4 竖屏**（1080×1440），当前项目用 1024×1536 ≈ 2:3 可以接受 |
| 色彩 | 主色调 ≤ 3 种，对比度差值 > 300 |
| 文字 | 封面大字 ≤ 7 个汉字 |
| 构图 | 左 1/3 问题态 + 右 2/3 解决态 |
| 信息传递 | **0.8 秒内传递核心信息** |

### 标题公式

**前 18 个字嵌入 2 个核心关键词**（算法只用前 18 字提取语义单元）

四大公式：

| 公式 | 晚霞账号示例 |
|------|-------------|
| 数字 + 价值点 | 「杭州今晚 87 分！今年最高分火烧云即将上演」 |
| 疑问 + 好奇心 | 「为什么昨天的晚霞特别红？3 分钟看懂云层秘密」 |
| 场景 + 共鸣 | 「下班正好赶上！杭州今天晚霞时间是 18:42」 |
| 痛点 + 方案 | 「又错过昨天的火烧云？今天这 3 城机会最大」 |

### 正文结构（三层信息密度拉停留）

```
第一层 认知锚点 → 今天哪几个城市晚霞条件最好
第二层 过程验证 → 云层高度/空气湿度/日落角度分析
第三层 结果确证 → 最佳观赏时间 + 推荐机位 + 感官描述
```

### 互动钩子（提升 CES，必须加！）

- 正文第 3 段插入：**「你拍到的晚霞是什么颜色的？评论区晒图👇」**
- 文末加：**「明天想看哪个城市？评论区告诉我，优先安排」**
- 评论引导：发完笔记后自己先在评论区写一条引导语

### 标签策略

- **1 个热门主标签** + **3-5 个精准长尾标签**
- 不要堆砌！话题标签对搜索排名零贡献
- 示例：`#晚霞预报` `#杭州晚霞` `#火烧云` `#追光者` `#今日晚霞`

| 早 9 点集中发布潮 | ❌ | 大量内容上线稀释曝光 |

### 晚霞账号的发布节奏

- **预报帖**：当天下午 16:00-17:00 发布（留时间给粉丝准备追霞）
- **知识帖**：晚间 20:00-21:00（休闲学习时段）
- **返图帖**：晚霞结束后 1-2 小时（趁热度）

## 六、wanxia 项目改进清单

基于以上研究，当前晚霞预报小红书内容需要改进：

### 🔴 紧急（影响曝光）

- [ ] **封面重新设计**：当前封面是大字标题 + 地图截图，改为「晚霞照片感 + 核心信息（城市+分数+时间）」的三色简洁构图
- [ ] **标题重写**：从「☁️ 成都晚霞 · 63分 好」改为「成都今晚 63 分！通透天空 + 最佳观赏时间 19:15」
- [ ] **加互动钩子**：每篇正文结尾加评论引导语
- [ ] **POI 位置标签**：每条笔记挂城市 POI（提升 70% 曝光！）
- [ ] **标签精简**：当前标签太多，改为 1 热门 + 4 精准

### 🟡 重要（提升质量）

- [ ] **正文去技术化**：把"云层高度 3000m"转译为"云在高处，容易染上颜色"
- [ ] **添加感官描述**：不只是分数，写"天空会从橙黄渐变到深紫"
- [ ] **机位推荐**：高分城市附 1-2 个最佳观赏点
- [ ] **时效性强化**：加入"还有 X 小时日落"的倒计时感

### 🟢 加分（差异化）

- [ ] **知识科普系列**：每周一篇"怎么看云识晚霞"
- [ ] **粉丝返图合集**：评论区引导晒图 → 第二天做 UGC 合集帖
- [ ] **城市 PK 系列**：「今天全国 TOP3 晚霞城市对决」
- [ ] **建立追霞群**：在简介放群链接，沉淀铁粉
