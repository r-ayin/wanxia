# wanxia — 需求文档

> 阶段：① 需求 | 2026-06-20 | 基于已实现功能反向文档化 + 未满足需求

## 项目愿景

用气象数据 + AI 预测晚霞质量，自动化生成小红书内容，建立一个"知道什么时候抬头看天"的预报账号。

## 核心用户

| 用户类型 | 需求 | 当前满足度 |
|---------|------|-----------|
| 追霞爱好者 | 知道今天晚霞好不好、去哪看 | 🟢 满足 |
| 摄影爱好者 | 最佳机位 + 黄金时刻 | 🟢 满足 |
| 普通刷到的路人 | 被打动、想出门、想互动 | 🟡 文案升级中 |
| 社群粉丝 | 互动、返图、归属感 | 🔴 未满足 |

## 已实现功能（v3.3）

### F1. 晚霞预测引擎
- 80 城市 open-meteo 气象数据采集
- 多因子评分模型（云层/湿度/能见度/气溶胶）
- 预取调度器（黄金时段 15min / 夜间 2h）
- 前端等高线可视化（Leaflet + 高德瓦片）

### F2. 小红书内容管线
- 文案引擎 v3.3：标题≤17字 + 4种诗意叙事 + 日期上下文 + 温情互动
- AI 封面图：GPT-Image-2，1024×1536 (2:3)，5 套模板轮换
- 截图生成：全国等高线 + 城市缩放（zoom=12）
- 一键素材包：截图 + 文案 + posts.json

### F3. 自动发帖
- Playwright v11：addInitScript 强制 Shadow DOM open + btn.click() 穿透
- 双引擎切换（Playwright / Browser Use）
- Cookie 4h 保活心跳

### F4. Cron 调度
- 12:00：生成素材 + 自动发帖
- 22:00：社媒数据采集
- 23:00：天气校准
- 23:30：社媒校准

### F5. 内容策略
- 核心城市每日必发（杭州/广州/厦门/北京/上海）
- 无晚霞时播报预测帖
- 分数分档标签（高分 #火烧云 / 低分 #日落收集计划）
