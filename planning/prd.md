# wanxia — PRD（产品需求文档）

> 阶段：② PRD | 2026-06-20 | 反向文档化已实现功能 + 下一迭代规划

## 产品架构

```
┌─ 数据层 ────────────────────────────────────────┐
│  open-meteo API → 预取调度器 → 内存缓存 → SQLite │
│  80 城市 × 2 天预报 × 15min 刷新（黄金时段）      │
├─ 预测层 ────────────────────────────────────────┤
│  多因子评分: 云层(高/中/低) + 湿度 + 能见度 + AOD │
│  颜色预测: 主色调 + hex + 叙事变体                 │
│  趋势感知: 3日连续 + 5日持续高位检测               │
├─ 内容层 ────────────────────────────────────────┤
│  文案引擎: 标题≤17字 + 4种叙事结构 + 日期上下文     │
│  封面引擎: GPT-Image-2 + 5模板 + 城市地标          │
│  截图引擎: Playwright + Leaflet zoom=12            │
├─ 发布层 ────────────────────────────────────────┤
│  v11 Playwright: Shadow DOM 穿透 + 键盘导航兜底    │
│  Cron: 12:00 发帖 / 22:00 采集 / 23:00 校准       │
└──────────────────────────────────────────────────┘
```

## 核心功能规格

### F1. 文案引擎 v3.3

| 规格项 | 值 |
|--------|---|
| 标题长度 | ≤17 字（含 emoji） |
| 正文结构 | 4 种叙事结构轮换（A/B/C/D） |
| 日期感知 | 夏至/端午/周末/暑假/年中 自动注入 |
| 天气叙事 | 温度+天气+湿度 → 诗意语言转换 |
| 互动模式 | 温情小故事（3-4句）→ 引出问题 → 活泼语气 |
| 标签策略 | 1热门+4精准，高分动态加 #火烧云 |

### F2. AI 封面引擎

| 规格项 | 值 |
|--------|---|
| 尺寸 | 1024×1536 (2:3) |
| 模板 | 5 套轮换（国家地理/爆款/氛围感/明信片/极简） |
| 中文渲染 | 97-99% 准确率，Exact Chinese text 约束 |
| 地标库 | 31 城市英文地标描述 |
| 覆盖 | 全国播报 + 全部城市帖 |
| 重试 | 最多 2 次，间隔 10s |

### F3. 自动发帖 v11

| 规格项 | 值 |
|--------|---|
| Shadow DOM | addInitScript 强制 open 模式 |
| 点击策略 | A: shadowRoot btn.click() → B: MouseEvent → C: force click → D: 文本匹配 |
| 遮罩处理 | history.replaceState + Escape×2 |
| 标题输入 | keyboard.insert_text() 模拟粘贴 |
| 成功检测 | /success 或 published=true 或 按钮消失 |
| 帖间间隔 | 120s（默认） |
| 每日上限 | 3 篇（可配置） |

## 下一迭代：v3.4 内容矩阵

### Sprint Goal
从"每日预报"扩展为"知识科普 + 粉丝返图 + 城市PK"三类内容

### Story 1: 知识科普系列
- 每周自动生成 1 篇科普帖（怎么看云识晚霞、为什么夏天晚霞更好看）
- 规格：godtier-deep-research 研究 → 拆分为 4-5 篇 XHS 短文
- 验收：1 篇/周，互动率 ≥ 预报帖均值

### Story 2: 粉丝返图合集
- 从评论区收集粉丝晒图 → 周末生成 UGC 合集
- 规格：手动筛选 5-10 张优质返图 + AI 写合集文案
- 验收：1 篇/周

### Story 3: 城市 PK 系列
- 当日 TOP 3 城市晚霞对比
- 规格：AI 封面用对比构图（3 城市并列）+ PK 文案
- 验收：每周至少 1 篇

## 非功能需求
- 封面 API 日均费用 ≤ $1（当前 ~$0.20/天）
- 发帖成功率 ≥ 80%
- 素材生成 ≤ 180s（含封面）
- 服务器内存 ≤ 512MB
